# 💣 Buscaminas (Minesweeper) - Java

Un clásico juego de **Buscaminas** desarrollado en **Java**.

## 📱 Descargar la aplicación (APK)

Podés descargar la versión para Android desde el siguiente enlace:

**[⬇️ Descargar APK](https://github.com/SebastianCimalando/BuscaMinas-Android/releases/download/v1.0/app-release.apk)**

> **Nota:** Una vez descargado, habilita la instalación de apps de orígenes desconocidos en tu dispositivo Android para poder instalarlo.

---

## 🎮 Características

- Clásico Buscaminas
- Desarrollado en Java
- Versión para Android

---

## 🛠️ Requisitos

- Android 5.0 o superior (aprox.)
- Espacio suficiente para instalar el APK

---

## 📂 Cómo instalar

1. Descargá el archivo `.apk` desde el enlace de arriba.
2. Abrí el archivo desde el administrador de archivos de tu celular.
3. Si aparece el aviso de Play Protect, tocá **Más detalles → Instalar de todos modos**.
4. ¡Listo! Ya podés jugar.
